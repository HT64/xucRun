# Contributing to xucRun Core

## Current contribution policy

The xucRun Core source is planned to be published under the Apache License 2.0. During the initial
publication and stabilization phase, code changes are maintained exclusively by the maintainer.
External pull requests are therefore not accepted at this time.

Bug reports and reproducible test cases are still valuable. Suspected vulnerabilities must never
be posted publicly; use the confidential process documented in `SECURITY.md`.

This policy can be reconsidered later. Accepting external code contributions will require an
explicitly documented contribution process and appropriate licensing declarations before the
first external pull request is merged.
