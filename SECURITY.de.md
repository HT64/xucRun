# Sicherheitsrichtlinie

**Sprache:** Deutsch | [English](SECURITY.md)

## Unterstützte Versionen

Nur die jeweils neueste veröffentlichte xucRun-Version wird unterstützt.

## Eine Schwachstelle melden

Ungepatchte oder vermutete Schwachstellen dürfen nicht in einem öffentlichen Issue, einer
Diskussion, einem Pull Request oder einem anderen öffentlichen Kanal gemeldet werden.

Verwende GitHub Private Vulnerability Reporting für das Repository `HT64/xucRun`:

1. Öffne die Registerkarte **Security** des Repositories.
2. Wähle **Report a vulnerability**.
3. Beschreibe das Problem, die betroffene Version oder den Commit, die Reproduktionsschritte, die
   erwartete Auswirkung und bekannte Gegenmaßnahmen.

Übermittle nur vertrauliche Daten, die zum Verständnis des Problems erforderlich sind. Reale
Kennwörter, private Schlüssel, Zugriffstoken oder nicht betroffene personenbezogene Daten dürfen
nicht übermittelt werden.

Die weitere Kommunikation erfolgt über den privaten Bericht. Reaktions- und Behebungszeiten hängen
von Reproduzierbarkeit, Schweregrad und Implementierungsrisiko ab; diese Richtlinie verspricht
weder eine feste Bearbeitungszeit noch eine Prämie für Schwachstellen.

Bitte vermeide eine öffentliche Offenlegung, bis eine Korrektur oder koordinierte
Sicherheitsmeldung verfügbar ist.

## Geltungsbereich

Diese Richtlinie gilt für Quellcode und veröffentlichte Pakete aus `HT64/xucRun`. Software von
Drittanbietern und veränderte Builds gehören nicht zum Unterstützungsumfang.
